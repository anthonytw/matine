# Credits and licenses

Every title in the demo library is either licensed CC BY (attribution required, given here, on the website's /credits page, and in an XML comment in
each title's NFO) or in the US public domain. The server holds no film: each title is a tiny placeholder video, and the posters,
backdrops and episode thumbs are single frames of the films themselves (with title lettering on posters). Frames were
read from the sources below; no third-party posters, logos or databases were used.

License was checked against the official source, not an uploader's tag.

## Dropped

* Agent 327: Operation Barbershop: Blender Studio releases it as CC BY-ND (no derivatives; frames and placeholders are derivatives).
* Hero and Charge (Blender Studio): no film-specific official license page found (only the general Studio terms, and the
  Internet Archive tags disagree), so not verifiable.
* Apollo 13: "Houston, We've Got a Problem" (JSC 548): contains network television news footage.
* Apollo 16: "Nothing So Hidden" was reachable only through an archive.org storage node that timed out; Apollo 8 took its place.
* Pioneer One (the old demo's series): CC BY-NC-SA, non-commercial.
* The Internet Archive's own license tags were not trusted (several Spring and Elephants Dream uploads say PD, ND or
  NC); the Blender project pages above were.
